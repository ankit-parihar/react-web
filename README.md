# Elementum

A modern agency website built with React. Clean design, smooth animations, fully responsive.

🔗 **Live Site:** [react-web-five-drab.vercel.app](https://react-web-five-drab.vercel.app)


## About

Elementum is a creative agency landing page featuring bold editorial typography, scroll animations, and a clean modern layout — built entirely in React without any UI libraries.

## Tech Stack

- React + Vite
- Google Fonts (Playfair Display, DM Sans)
- Deployed on Vercel
